# 🎭 Playwright POM Practice

This project demonstrates automated testing using Playwright with the Page Object Model (POM) design pattern.

## 🚀 Technologies Used
- Playwright
- TypeScript
- Node.js

## 📂 Project Structure

pages/
  LoginPage.ts
  HomePage.ts
  ProductsPage.ts

tests/
  login-pom.spec.ts
  products-pom.spec.ts

## 🧪 Tests Included

### 🔐 Login Tests
- Valid login
- Invalid login
- Empty login fields

### 🛍️ Product Tests
- Navigate to product category
- Open product page
- Verify product page is visible

## ▶️ Run Tests

```bash
npx playwright test
